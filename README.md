# Mon compte

Application de suivi de dépenses pour les salariés : un seul fichier, `index.html`, qui s'ouvre dans le navigateur. Aucune donnée ne quitte l'appareil.

Version indépendants : [mes-comptes](https://github.com/omesnage/mes-comptes). Le code source des deux versions est dans ce dépôt, `mon-compte` ne contient que le site prêt à publier.
